# Overview
This is a couple of scripts/configs to fully automate window configurations (size/postion) for all the windows on your Linux desktop.  The instructions for using this are included in the wiki linked below.

**Support for Wayland is available** with the latest version of the [Window Calls Gnome Extension](https://extensions.gnome.org/extension/4724/window-calls/)

# Install/Usage Instructions
